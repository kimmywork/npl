## 2026-10-23 11:40 CST — E2a closure-compiling evaluator

- `src/compiler/frontend/library-definitions.npl` (new):
  `(%library-definitions (npl primitive))` expands to
  `(("npl/primitive" (name . value) ...))`, the 164 generated
  `(npl primitive)` value names bound to their compiled procedures.
  Other libraries are rejected until E2b. Seed relay.
- `lib/npl/evaluator-compile.scm` (new, 460 lines): core AST to native
  closures. Locals are lexical addresses into frames `#(parent v ...)`,
  globals are cells in a 509-bucket table (unbound cells raise
  `unbound identifier: x` when read, so later REPL definitions fill them),
  lambdas of 0-4 fixed and 0-2 + rest parameters are native lambdas of the
  same shape (native arity error), applications of 0-3 operands are
  specialized. Compound tests avoided (control conversion duplicates if
  continuations).
- `lib/npl/evaluator-session.scm` (rewritten, 180 lines): environments,
  eval, load, `(npl eval-runtime)` hooks, `eval-condition-text`. The
  primitive bindings come from `%library-definitions`; `list` is added
  (not a table row). Intentional duplication: `+ - * < > = <= >=` values
  accept at most required+6 operands (PRIMITIVE-VALUE-SPREAD), so longer
  calls fold pairwise through the same native operator.
- Deleted `evaluator-core.scm`, `evaluator-control.scm`,
  `evaluator-primitives.scm`, `evaluator-records.scm` (about 1,800 lines:

## 2026-10-23 12:50 CST — E2b standard libraries bound natively in npli

- `src/compiler/frontend/library-definitions.npl`: `%library-definitions`
  now takes any library. Each entry is `(key checksum (name . value) ...)`:
  every definition of the expanded body, keyed by its emitted name without
  the library prefix, with a hash of the parsed declarations (including
  included files). Library entries gained an info cell (prefix, parts,
  expanded body) recorded by `library-record-load!`, which `library-load`
  now calls instead of appending to `LIBRARY-OUTPUT` itself.
- Native hook: `frontend-set-native-hook!` (`lib/npl/frontend.sld`). When
  the evaluator's hook reports the same definition names and checksum, the
  expanded body is replaced by `(%eval-bind-native key pairs)`, which binds
  each cell to the compiled value; otherwise the body is evaluated from
  source as before. nplc never sets the hook.
- `lib/npl/evaluator-session.scm`: `EVAL-NATIVE-LIBRARIES` covers
  `(npl primitive)` and 12 standard libraries (base 213 definitions, char
  31, cxr 24, inexact 16, file 9, ...); `eval`, `load`, `repl`, `r5rs`
  stay evaluated from source (they act on the running evaluator). No
  definition name in the table is a hygienic or other unstable name.
