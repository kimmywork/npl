  every definition of the expanded body, keyed by its emitted name without
  the library prefix, with a hash of the parsed declarations (including

## 2026-10-23 13:30 CST — E3 evaluator tuning: all bench workloads under 30 s

- `lib/npl/evaluator-compile.scm`: an application whose operator names a
  global reads the procedure from its cell when called (R7RS leaves operator
  and operand order unspecified; the cell is read last), instead of calling
  an operator closure.
- Two-operand calls to `+ - * = < > <= >=` whose cell holds
  `(scheme base)`'s numeric procedure at compile time apply the operator in
  the evaluator's own source, whose compiled fixnum fast path falls back to
  that same library procedure (numeric-aliases), so results and errors are

  `PUBLIC-NUMERIC-ALIAS-SOURCES`), so it names the same procedures the
  compiler treats as aliases.
