## 2026-09-29 15:45 CST — closure conversion, global GC roots, test harness

Reason: the stage review found `mixed-numeric-utilities` already implemented
and gated (workstate was stale), and that test/relay time was dominated by
allocation, not by test design. Profiling (macOS `sample`) attributed 70-80% of
samples to GC sweep/allocation in the evaluator core test (237 s, 3 GB RSS) and
the relay. Root causes were in code generation.

Changes:
- `src/compiler/backend/environment.npl`: lexical entries are `(name cell? . op)`.
  `env-bind` allocates a cell only for `set!` targets (`collect-assigned`);
  `lambda-captures` captures only referenced innermost bindings (replaces
  `visible-env`). Both analyses skip literal data (circular datum labels hang
  a naive walk) and over-approximate by ignoring shadowing.
- `tail.npl`, `bindings.npl`, `expression.npl`: reads use `env-read`; `let`,
  `let*`, and parameters use `env-bind`; `letrec`/internal definitions keep cells.
- `program.npl`/`state.npl`: removed dead `CURRENT-FUNC`, `CURRENT-PARAM-CELLS`,
  `parameter-cells`, `bind-params`, `render-params`, `has-runtime-globals`,
  `emit-empty-global-inits`, `INIT-EMITTED`. `$npl_global_inits` now registers
  every `$gv_` slot as a GC root.
- Latent defect found by function-level SSA bisection after capture filtering
  broke self-compilation: data-segment globals were never GC roots; previous
  programs survived only because full-environment captures conservatively kept
  values reachable. Six-line repro: `set!` a global list, allocate, read it.
- `runtime/alloc.c`: growable root table (was fixed 1,024);
  `NPL_GC_THRESHOLD_BYTES` test override. Default 1 GiB kept: 64/256 MiB were
  measured slower (149/113 s vs 100 s self-compilation).
- Tests: `src/compiler/tests/gc-roots.npl` (1 MiB threshold in
  `check_full_compiler.sh`; fails on the previous compiler, passes now);
  shared fixture `tests/r7rs/fixtures/mutable-bindings` (16 shadowing/`set!`/
  capture cases, Guile oracle) added to `run_tests.sh`.
- `tools/prop_tests.py`: P1 runs its independent cases in a thread pool
  (`--jobs`); a mutated model still reports failure.
- `bootstrap/current.ssa` regenerated: 184,776 lines, SHA-256 `49a41dd9...`.
