## 2026-10-08 15:49 CST — L0b registered primitives as first-class values

- Native code: a registered primitive in value position (`(map car xs)`,
  `(f cons)`, `(vector-ref table 0)` of `null?`) now compiles to a closure over
  a wrapper generated once per program (`src/compiler/backend/
  primitive-values.npl`). Wrappers follow the CPS closure ABI, reuse the
  ordinary emission path, take their arity from `backend/primitives.npl`, and
  dispatch on argc for optional-port and variadic rows; `count` rows pass argv
  through. Wrong counts call new `npl_wrong_argument_count`. Names are by table
  index (`_npl_prim_N`) because sanitized names collide.
- `string-append` is now a variadic `count` primitive (`npl_string_append_n`),
  so `(string-append)` is `""` as in R7RS; the old fold helper is gone.
- Evaluator divergences exposed by the shared fixture and fixed:
  `string-append` was binary only; `display`/`write`/`newline` ignored the
  optional port argument; `get-output-string` was missing.
- New shared fixture `tests/r7rs/fixtures/procedure-values` (unary, binary,
  numeric, variadic, returned, stored, output-port procedures); native compile
  failed before.

Evidence: two-pass relay, then strict relay from the installed seed: 194,825
