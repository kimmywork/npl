## 0.1.1 release hardening (branch `release/0.1.1`)

Started from the read-only review recorded in
[2026-11-12-0.1.0-state-review](../reviews/2026-11-12-0.1.0-state-review.md).
The branch fixes the release blockers and the two most visible diagnostic
defects; it does not change language semantics.

- Release files: MIT `LICENSE`; `docs/README.md` and the root `README.md`
  symlink to it; Linux-only GitHub Actions gate
  (`.github/workflows/ci.yml`, `ubuntu-24.04`, no relay).
- Version: `VERSION` and `project(npl VERSION ...)` are 0.1.1;
  `src/compiler/common/version.npl` is the single source constant for
  `nplc --version` and `npli --version`. `check_driver.sh` checks the three
  values, and `check_install.sh` checks the installed binaries.
- Gate locale: `tools/utf8_locale.sh` selects `C.UTF-8` on Linux and
  `en_US.UTF-8` on macOS (override `NPL_TEST_LC_ALL`); `run_tests.sh`,
  `run_r7rs_fixture.sh`, and `run_chibi_suite.sh` source it. The 0.1.0
  review failed `unicode-strings` and `unicode-char` only because Guile
  escaped non-ASCII output under `LANG=""`.
- Compiler diagnostics: `fatal`, `fatal2n`, the reader paren/byte errors,
  and the backend datum/unknown-call errors write to standard error with the
  `nplc:` prefix. `driver-emit-ssa` no longer relays the partial SSA file;
  an arity error after SSA emission is now 69 bytes on stderr instead of
  37,387 lines / 974,786 bytes. `check_driver.sh` guards this.
- Features: `features` advertises `full-unicode`, `ratios`,
  `exact-closed`, `exact-complex`, `ieee-float`, `posix`, and `unix`;
  `cond-expand` accepts the same identifiers and treats an installed
  `(srfi ...)` or user library as available when its `.sld` file exists, not
  only after it is loaded. The `libraries` suite grows from 16 to 20 tests
  (including a new `conditional-only` library).
- Docs: `docs/testing.md` now reports 56/57 stages and 30/77 compiler
  checks, `docs/toolchain.md` reports the 11.1 G self-compilation figure and
  the new `--version`/stderr contract, `docs/extending.md` and
  `docs/r7rs-conformance.md` describe the feature list and library
  detection.
