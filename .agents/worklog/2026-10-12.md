## 2026-10-12 12:43 CST — Chibi R7RS suite on npli; reader and write fixes (batch 1)

- New `tools/run_chibi_suite.sh` with a minimal portable `(chibi test)`
  (`tests/chibi/chibi-test.sld`, chibi's comparison rules) runs
  chibi-scheme's `tests/r7rs-tests.scm` through the npli REPL (form by
  form, so one unsupported form does not stop the run). Guile 3.0 cannot
  run the file (syntax error at line 540), so this suite has no Guile
  baseline.
- Result after this batch: 1100 passed, 28 failed, 68 top-level forms
  aborted (their tests not counted). Before it the run stopped at the
  first unsupported syntax.
- Fixes: runtime `read` gains ` , ,@ (previously read as symbols; npli
  source with quasiquote failed), `#|...|#`, `#;`, `#!fold-case` /
  `#!no-fold-case`, `|symbol|` (with escapes); the compiler lexer gains
  `#|...|#`, `#;` (token 18, skipped by the parser), `|symbol|`,
  `#true`/`#false`, `#e`/`#i`; numbers accept `#e`/`#i` with an
  optional radix in either order; `write` bars symbols that would not read
  back; `list?` terminates on circular lists (\#f); npli `quote` of a
  symbol with spaces (frontend converted names through `read`).
- Remaining (classified): reader string line continuations, `#;` before
  `.`, complex syntax (+i, -2i, 1+2I, +nan.0i, 3.0+inf.0i), `#d1.`,
  shortest output of subnormals, `+NaN.0` case variants;
  `case-lambda` rest/whole formals, `define-values` dotted formals,
  macro-generated `define-syntax` in bodies and top-level `begin`,
  catchable `apply` errors, two macro hygiene cases. Exponent markers
  s/f/d/l are a chibi extension (not R7RS).

`tools/run_tests.sh --skip-current-fixed-point` all PASS.

## 2026-10-12 15:43 CST — Chibi R7RS suite batch 2: 1207 passed, 4 failed

Result (npli, `tools/run_chibi_suite.sh`): 1207 passed, 4 failed, 10
forms aborted (was 1100 / 28 / 68).

- Numbers: rectangular complex syntax (`+i`, `-2i`, any-case `i`,
  infinities and NaNs in either part, exponent signs), `<infnan>` in any
  case, `#d` with decimals, complex output without a doubled sign;
  inexact output in Guile's form (`5.0e-324`, `1.0e21`).
- Reader: `#true`/`#false`, `#e`/`#i` in the runtime reader, string
  line continuations, `#;` must skip a datum (not a dot), a dot needs a
  datum after it; compiler lexer token 19 for `|...|` symbols so `|.|`
  is not the dot.
- `write`: symbols are barred unless they match the R7RS identifier
  grammar (peculiar identifiers that read as numbers are barred).
- Syntax: `define-values` with dotted and single-identifier formals;
  syntax-rules list patterns no longer match frontend atoms (case-lambda
  rest/whole clauses); a literal `_` matches only `_`; literal and
  pattern-variable identity uses name and syntax mark (bound-identifier=?),
  fixing macro-defining macros; macro output `define-syntax` in bodies;
  top-level `begin` splices before expansion and predeclares only value
  names (keywords were predeclared as variables and shadowed); npli keeps
  the final top-level environment after a splice.
- `apply` argument errors are catchable error objects (native and npli).
- Remaining 4 failures, all classified, not NPL bugs:
  `(sqrt -1.0-0.0i)` (Guile and Racket also give 0.0-1.0i, the
  IEEE branch for -0.0; open user decision), `|+NaN.0abc|` (R7RS grammar
  makes it a plain identifier; Guile and Racket print it unbarred),
  `1.7976931348623157e+308` vs Guile's and NPL's `...e308` (two accepted
  spellings, chibi's list has only one). 10 aborted forms are the R5RS
  exponent markers s/f/d/l, not R7RS syntax.

Evidence: relay and strict relay, 218,287 lines, SHA-256 `0cc1ad7b...`;
`tools/run_tests.sh --skip-current-fixed-point` all PASS.
