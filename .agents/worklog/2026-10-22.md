## 2026-10-22 13:30 CST — P2b library-declared C primitives

- `src/compiler/frontend/c-primitives.npl` (new): top-level
  `(define-c-primitive (name (param type) ...) result ["c-symbol"])`
  registers a `fixed` row with its types in `DECLARED-PRIMITIVE-ROWS`
  (consulted by `primitive-row` after the table) and binds the name to it;
  `%c-call` and `%c-procedure` register the same rows inline. Calls are
  direct `call $symbol(...)`, value uses share the P1 wrapper, and
  import/rename/prefix work as for any binding. A symbol already registered
  keeps its row (table or earlier declaration) and must match its operand
  count. Types: fixed vocabulary of 15, recorded only. npli's frontend
  rejects the forms until P5 (`C-PRIMITIVES-SUPPORTED`).
- Implemented as a frontend declaration rather than a macro over `%c-call`
  (design section 1 updated): NPL has no identifier macros, and a wrapper
  procedure would add a CPS call per use (user-chosen option).
- `frontend/expand-values.npl` (new): let-values/define-values expansion
  moved out of `expand.npl` (852 -> 676 lines) before adding the hooks.
- Size finding: control conversion copies an if's continuation into both
  branches, so nested-if/and/or tests multiply the code after them. The
  first draft grew the seed by 28,675 lines (one helper alone 18k); with
  single-predicate tests it is 7,384 lines. Recorded in the file header;
  a join-continuation fix in control conversion is a separate decision.
- Seed relay: `bootstrap/current.ssa` 233,699 lines, SHA-256
  `35f6a535fa43630d65d69081be90e0f86768337c0f571c9da1a8a166d2c7b3a2`.

Evidence: new suite `c-primitives` (library declarations with explicit and
rule-derived symbols, prefix and rename imports, value use through `map`
and `apply`, `%c-call`, `%c-procedure`, a declaration sharing `npl_car`, a
catchable error from a declared call) PASS 11; the gate also checks the
direct call and a single wrapper in its SSA; four new reject_compile
contracts; npli rejection in check_repl.sh. All 28 existing compiler test
programs emit byte-identical SSA (old toolchain vs gen1).
Toolchain rebuilt from the new seed; `tools/run_tests.sh
