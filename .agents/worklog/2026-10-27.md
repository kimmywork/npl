## 2026-10-27 CST — P6b define-c-function with generated C stubs

Decided with the user (2026-10-24/25): nplc builds stubs automatically and
`nplc --emit=c-stubs` writes them for npli; nplc links the same stubs;
pointer-out results return as extra values.

- `(define-c-function name "c_symbol" (type ...) -> result)`
  (`src/compiler/frontend/c-functions.npl`, new): types int, long, int64,
  size_t, double, bool, string, pointer, pointer-out (argument only), void
  (result only). Records one entry per C symbol in DECLARED-C-FUNCTIONS
  (a second, different signature is an error) and registers the stub
  `npl_cfn_<c_symbol>` as a C primitive, so calls, value uses, imports,
  and npli's symbol lookup are those of define-c-primitive. More than one
  result uses the `values` result type.
- `src/compiler/backend/c-stubs.npl` (new): writes a C99 file, one stub per
  entry: check and convert every argument first, copy strings, call, box
  the results, free the copies last (a result may point into one).
- `runtime/ffi.c`: npl_ffi_to_int64/uint64 (range checked, bignums through
  decimal text), to_double, to_bool (only #f is false), to_pointer,
  check_string (no NUL), copy_string, free, and from_* boxing; npl.h
  declares them.
- `src/compiler/driver.npl`: kind `c-stubs` (stdout or -o; expansion runs
  before the output is opened). An exe build's SSA child run also writes
  the stubs (internal `--c-stubs-file`), so the program is expanded once;
  the driver compiles them with `-I` the installed `include/npl` (or
  `NPL_INCLUDE`) and links them before the -l libraries; failure reports
  "cc (c stubs)". npli's lookup error names the stub and how to build it.
- Seed size: the first version grew the seed by 11,145 lines, 1,653 of
  them in driver-run: non-tail and compound ifs in new code duplicated the
  rest of their procedures in control conversion. Rewritten as tail-
  position helpers; growth 8,033 lines for about 450 new source lines.
- Tests: `src/compiler/tests/c-extension/typed.{c,npl,out}` (every type,
  two pointer-out cases, with-resource, value use, libc strlen/abs, six
  argument errors); stubs compile with -Wall -Wextra -Wpedantic -Werror.
  Run by check_full_compiler.sh (hand link), check_driver.sh (automatic
  build, --emit=c-stubs, failed stub compile), check_repl.sh (npli -l with
  a stub library), check_install.sh (installed nplc). Six contracts
  `contracts/c-function-*.npl`.
