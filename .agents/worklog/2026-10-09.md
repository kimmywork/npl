## 2026-10-09 11:22 CST — hygiene for definition-producing macros

Found while preparing L4 (define-record-type expands to several definitions):
native compilation failed for any macro whose output is `(begin (define ...)
...)` referencing a definition-site binding, e.g. `(begin (define a (+ v 1)))`
gave "unbound identifier: +". Such output is spliced unexpanded, so its
template identifiers (carrying the transcription mark) were resolved later
without the transformer's alias environment. The evaluator path happened to
work.

- `src/compiler/frontend/transcription.npl` (new): free marked identifiers in
  spliced output are re-marked and bound to their definition-site meaning in
  `TRANSCRIPTION-ALIASES` (consulted by `lookup-value-binding`; persisted in
  REPL sessions).
- Names defined by spliced output now join the scope: top-level ones are
  predeclared as globals, body ones are bound before the rest of the body
  expands (R7RS 5.3.2).
- New shared fixture `tests/r7rs/fixtures/definition-macros` (top level, body,
  generated procedure definitions, quoted data, shadowing at the use site);
  native compile failed before.

## 2026-10-09 19:40 CST — L4b batch 1: catchable primitive errors

- Mechanism (`runtime/error.c`, `runtime/control.c`): `npl_primitive_error
  (who, message, irritant)` builds an L4a error object (message
  "who: message", irritants `(irritant)`). With a handler, the runtime
  restores the innermost trampoline's GC root count, stack bottom, and
  escape depth, schedules the handler call (non-continuable raise), and
  longjmps to that trampoline. Without one it prints
  `who: message: irritant` and exits 1; uncaught raised error objects print
  the same way. `npl_gc_unroot` now removes from the top and keeps order, so
  a saved root count identifies the same prefix.
- Converted (native and npli, same text): car/cdr, vector-ref/vector-set!/
  vector-length type and range, literal mutation of pairs and vectors,
  char->integer, integer->char, string-ref, string/symbol argument checks,
  procedure arity, and "not a procedure". The evaluator raises through its
  handler chain (`eval-primitive-error`).
