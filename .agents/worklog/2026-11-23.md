# 2026-11-23

## Syntax-case completion and differential coverage

- Added `tests/r7rs/fixtures/syntax-case` (Guile `(rnrs syntax-case)` oracle)
  and `syntax-case-npl` (`oracle=none`, nplc/npli differential). The shared
  body covers clause selection, literals, ellipsis, nested/depth-two
  templates, vectors, with-syntax, recursive and mutually recursive macros,
  hygiene (introduced binders, definition-site free identifiers, nested
  macros), syntax helpers, local macros, top-level and body definitions,
  generated `define-syntax`, quasisyntax, and shadowing.
- Fixed transcription alias lookup: the alias table accepts a template
  copy's source mark as well as its own mark, so a macro generated by another
  macro resolves its definition-site bindings. Ordinary lexical entries still
  match only by mark, preventing a user binding at mark 0 from capturing a
  template identifier.
- Fixed top-level `begin` recognition when `(scheme base)` exports core
  syntax; a `begin` containing only `define-syntax` now splices.
- Fixed named `let` in the compile-time evaluator (name, bindings, and body
  were shifted by one).
- Added phase-1 `define-syntax` and evaluator `let-syntax`/`letrec-syntax`,
  so transformer bodies can use phase macros and local syntax-rules macros.
- `syntax-case-procedural` is 18 tests; both fixtures are registered in
  `tools/run_tests.sh`.

## F1: C memory core

- Added `runtime/ffi-memory.c`: aligned zero-filled allocation, owned
  pointer metadata (`base`, `size`, `offset`, `sized`, `owned`), explicit
  free, size queries, copying, pointer+offset views, typed loads/stores for
  u8/u16/u32/u64/i8/i16/i32/i64/float/double/pointer, and type widths.
- Extended `(npl ffi)` with `foreign-alloc`, `foreign-free`,
  `foreign-size`, `foreign-copy`, `pointer+offset`, `pointer-offset`,
  typed `pointer-ref-*`/`pointer-set-*!`, `pointer-ref`/`pointer-set!`,
  `c-type-size`, and `c-array`/`make-c-array`/`c-array-ref`/
  `c-array-set!`/`c-array->vector`/`vector->c-array`.
- Typed access uses `memcpy` after bounds and alignment checks; views carry
  the remaining length and cannot be freed; foreign memory stores only C
  scalars and addresses.
- Added `ffi-memory` compiler suite (42) and an nplc/npli `ffi-memory`
  fixture; documented the API in `docs/ffi.md`.
