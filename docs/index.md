# NPL documentation

NPL is a self-hosting R7RS-small Scheme implementation with a native
compiler (`nplc`, through QBE) and an evaluator and REPL (`npli`).
Status: 0.1.1.

This site mirrors the guides under `docs/`. For the project overview, quick
start, platform support, and license, see the
[repository README](https://github.com/kimmywork/npl#readme).
